## 💻 Quick Start & Local Setup

Clone the repository and run it locally in under 2 minutes:

```bash
# 1. Clone the repository
git clone https://github.com/vanshkesarwani/portfolio.git

# 2. Navigate to the project root
cd portfolio

# 3. Install dependencies
npm install

# 4. Start the local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the application with Hot Module Replacement (HMR).

### Other Available Scripts
```bash
# Create production build
npm run build

# Preview production build locally
npm run preview

# Run ESLint validation
npm run lint
```

## 🌐 Deployment on Vercel

This application is fully optimized for **Vercel** with single-page application (SPA) client-side routing.

A `vercel.json` file is included in the root:
```json
{
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ]
}
```

### Deploy to Vercel via CLI
```bash
npx vercel
```
Or simply connect your GitHub repository [vanshkesarwani/portfolio](https://github.com/vanshkesarwani/portfolio) to the Vercel Dashboard for automated CI/CD deployments on every push to `main`.
